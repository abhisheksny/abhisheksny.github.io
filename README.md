# abhisheksny.github.io

Personal research website for Abhishek Kumar.

## Deploy

1. Create a public GitHub repository named `abhisheksny.github.io`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The site will be available at:

https://abhisheksny.github.io
