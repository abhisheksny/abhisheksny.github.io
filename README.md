## Selected Projects

### FASTA Toolkit

Python/Biopython-based toolkit for sequence analysis, including FASTA statistics, ORF identification and protein translation.

[View repository](https://github.com/abhisheksny/bio_project)

### FACS Data Analysis

Python-based workflow for processing FCS files, generating visualizations and extracting analytical metrics from flow-cytometry data.

### qPCR Data Analysis

Analysis workflow for HPV qPCR data, including quality control, Ct-based interpretation and summary statistics.

### Protein–Ligand Simulation

Computational structural-biology workflows involving molecular docking, GROMACS molecular dynamics simulations and trajectory analysis.
